# دليل استخدام النظام بوضعية White Label

هذا المشروع مصمم ليكون **Template أساسي**. لإنشاء نسخة جديدة لعميل (صالون) جديد، يرجى اتباع الخطوات التالية بدقة لضمان استقلالية البيانات.

## الخطوة 1: تجهيز قاعدة البيانات (Supabase)
1. قم بتسجيل الدخول إلى [Supabase](https://supabase.com).
2. قم بإنشاء مشروع (Project) جديد باسم الصالون.
3. انسخ الرابط (`Project URL`) والمفتاح (`anon public key`) من إعدادات الـ API.

## الخطوة 2: تطبيق الجداول وقواعد الأمان (Migrations)
في الطرفية (Terminal)، تأكد من تسجيل دخولك في أداة Supabase عبر الأمر:
`npx supabase login`

ثم قم بربط المشروع الجديد ودفع الجداول:
1. `npx supabase link --project-ref <PROJECT_ID>`
   (حيث `<PROJECT_ID>` هو المعرف الموجود في رابط مشروع Supabase الخاص بالعميل).
2. `npx supabase db push`

هذا سيقوم بإنشاء جميع الجداول وإضافة القيود الأمنية تلقائياً، بما في ذلك سياسة منع الحجز المزدوج.

## الخطوة 3: تجهيز كود العميل (Repository)
1. قم بعمل نسخة (Fork أو Duplicate) من هذا المستودع (Repo).
2. في المستودع الجديد، قم بتعديل ملف المتغيرات البيئية (Environment Variables) ليحتوي على:
   ```env
   VITE_SUPABASE_URL=رابط_مشروع_العميل_هنا
   VITE_SUPABASE_ANON_KEY=مفتاح_مشروع_العميل_هنا
   ```

## الخطوة 4: النشر والتخصيص (Deployment)
1. قم بربط المستودع الجديد بمنصة النشر (مثل Vercel أو Lovable أو Netlify).
2. أضف الـ Environment Variables في إعدادات المنصة.
3. بعد اكتمال النشر، ادخل إلى لوحة التحكم بصلاحيات الأدمن (`admin`)، ومن هناك يمكنك تخصيص:
   - اسم المحل
   - الألوان (Dark/Light mode)
   - روابط التواصل الاجتماعي
   - مواعيد العمل

**ملاحظة**: لوحة الإدارة مجهزة بـ Supabase Realtime لإصدار تنبيهات صوتية عند وصول حجز جديد. تعمل هذه الميزة تلقائياً ولا تحتاج إلى إعداد إضافي.
